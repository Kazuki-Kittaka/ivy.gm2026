# ivy.gm2026

IVY専門学校 ITCSクラス「2026年GMクラスWebサイト選抜総選挙」の投票用ページです。

授業課題としてクラスメイトが制作したWebサイト24作品のサムネイルとリンクを一覧表示し、お気に入りの作品に投票できます。

# ページ構成
index.html — トップページ本体（ヘッダー、ランダム表示のサムネイルスライダー、作品一覧グリッド、投票ボタン）
styles.css — 全体のスタイル
script.js — サムネイルスライダーの生成・自動スクロール、カードのフェードイン演出
img/ — 各作品のサムネイル画像・背景画像
# 権利について
各作品はWeb制作学習の授業課題として制作された非営利のサイトです。作品に関する著作権・商標権等は各権利者に帰属します。
